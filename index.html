Is that video pirated?

A Python tool that checks whether a recorded video is a copy of an original, using perceptual image hashes and audio spectrograms.

Get startedView on GitHub

Try it

A simulation with made-up numbers. The real tool reads your videos with FFmpeg.

Runs anywhere

No external APIs. No deep learning. Classical signal processing, all on your own machine.

Quick start

  1. Install FFmpeg and make sure it is on your PATH.

    # Ubuntu/Debian
sudo apt install ffmpeg
# macOS
brew install ffmpeg

  2. Clone the repo and install the Python dependencies. Python 3.8+ is required.

    git clone https://github.com/Yashwanth-Kumar-26/MoviePiracy.git
cd MoviePiracy
pip install -r requirements.txt

  3. Put originalvideo.mp4 and recordedvideo.mp4 in the project folder.

  4. Run the detection.

    python main.py

  5. Optional: tune the thresholds in config.py.

    NUM_SAMPLES = 4
AUDIO_DURATION = 15
IMAGE_HASH_THRESHOLD = 10
AUDIO_SIMILARITY_THRESHOLD = 0.7
SCREENSHOT_MATCH_PERCENTAGE = 0.5

How it flows

Original videorandom timestamps
→

→
Phase 2same timestamps, recorded video
→

→
VerdictPIRATED or not
